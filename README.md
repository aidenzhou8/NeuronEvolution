# Neuron Evolution - Interactive Visualization

An interactive web app to explore how neurons in Pythia-70M and Pythia-160M evolve during pretraining, by extracting highly activating clusters at each checkpoint. Deployed at https://neuronevolution.streamlit.app/ as part of a research project on tracking feature superposition over model pretraining. In the future, I hope to expand this resource to cover a wider range of model sizes and architectures.
